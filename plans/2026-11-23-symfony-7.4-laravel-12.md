# DiBe: upgrade Symfony 6.4 → 7.4 LTS and Eloquent 10 → 12 (phase 3)

> **For agentic workers:** self-contained; execute after a context clear if needed.
> Required skills: superpowers:executing-plans, superpowers:verification-before-completion; on failures
> superpowers:systematic-debugging. Fresh reviewer subagent on the diff before the PR.
> **Create pull requests only. Never merge PRs and never push to `main`.**
> PHP/composer commands run in the container: `docker exec dibe-dev-symfony-1 sh -c 'cd /app && …'`.

## Context

Phases 1–2 (#143, #144) moved DiBe to Symfony 6.4 + Eloquent (illuminate) 10, as a stepping stone to Symfony 7 /
Laravel 11+. Laravel 10 no longer gets security fixes.

- **Coupled again:** illuminate 11+ requires Symfony 7 (illuminate/console 12 → `symfony/console ^7.2`), so Symfony 7
  and Laravel 12 move in one step.
- **Ceiling:** the released `wouterj/eloquent-bundle` 2.8.1 supports illuminate ^9–^12 and Symfony ^6–^7. Laravel 13 /
  Symfony 8 need the unreleased `symfony8` branch.
- Dry-run on `main` (34d0d9b): Symfony 7.4.23 + illuminate 12.73 + bundle 2.8.1 resolve; 65 updates, 12 installs,
  no removals.

**Decision (user):** Symfony **7.4 LTS** (security until ~Nov 2029) + **Laravel 12** with the stable bundle 2.8.1.
Laravel 12 security support ends ~Feb 2027 → follow-up step to Laravel 13 once the bundle releases support.

## Steps — branch `chore/symfony-7.4`, one PR

0. **Baseline.** `app/scripts/upgrade-snapshot.sh app/var/snapshots/before-phase3` on `main` (routes, ES sample dumps,
   28 endpoint bodies/redirects). Full-charter baseline: the phase 2 full dump (42,758 charters × en/fr), still valid
   for `main` (#145–#147, #153 don't change index output).
1. **Bump** (`app/composer.json`): every `6.4.*` → `7.4.*`, `extra.symfony.require: "7.4.*"`,
   `illuminate/database` + `illuminate/http` → `^12.0`. `composer update -W`.
2. **Fix what breaks** on boot / index / requests (Symfony 7 removals, Laravel 11/12 signature changes in models,
   resources, relation overrides, `ajcastro/eager-load-pivot-relations`).
3. **Recipes:** `composer recipes:update` per outdated recipe (one-off container with `.git`, see AGENTS.md); keep
   project customisations (translator fallbacks, prod logging, base.html.twig, phpunit.xml.dist).
4. **Rector:** `vendor/bin/rector process` with `withComposerBased(symfony: true)` (now applies the 7.x sets);
   dry-run, review, apply.
5. **Zero deprecations** from our code (container log, dev log on web + CLI); lint:container/twig/yaml/xliff.
6. **Docs:** AGENTS.md stack table (Symfony 7.4, Eloquent 12) and the Laravel 13 note.
7. **Verify:** snapshot vs baseline (routes, ES dumps, HTTP identical); full charter reindex byte-identical to the
   phase 2 dump; prod image builds and serves with `APP_ENV=prod`; vitest; browser check EN/FR.

## Out of scope

Laravel 13 / Symfony 8 (needs a bundle release); PHPUnit (#148); the open issues #149–#152.
